About the physics

Everything is integrated at 500 Hz (RK4) from the same equations as the Python package: 6-DOF rigid body, per-motor thrust T = CT ρ n² D⁴ with spin-up / spin-down lag, drag relative to the moving air, log-law wind, Dryden turbulence (MIL-F-8785C), 1 − cos gusts, ISA air density from temperature and altitude. The browser version matches the Python simulator to 10⁻¹³ m on deterministic test flights.

The controller only knows the nominal model: it is not told the temperature, the altitude or which motor is damaged. Iris and X500 use parameters from PX4's Gazebo models, the Crazyflie those of gym-pybullet-drones.
